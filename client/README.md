# 🎬 Watch Party Frontend

A real-time Watch Party application frontend built with React and Socket.IO that allows users to watch YouTube videos together in synchronized rooms.

## ✨ Features

- 🎥 Synchronized YouTube video playback
- 👑 Host & Participant roles
- ⏯️ Real-time Play/Pause synchronization
- ⏩ Video seek synchronization
- 🔗 Join rooms using Room ID
- 👥 Live participant list
- 📺 Change videos instantly for all users
- 📱 Fully responsive design
- ⚡ Fast and modern UI

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Socket.IO Client
- React Router DOM
- React YouTube
- React Icons

## 🚀 Setup

```bash
git clone <repository-url>
cd watch-party-frontend
npm install
npm run dev
```

Create a `.env` file:

```env
VITE_SERVER_URL=http://localhost:5000
```
